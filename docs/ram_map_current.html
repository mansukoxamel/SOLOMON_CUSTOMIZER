4. 絶対に繰り返さない事故

$0460/$0461 は空きではない。
暗闇モード初期実装で $0460/$0461 をROOMFLAGS/暗闇カウンタに使ったが、実体はサウンドch0状態 $0456+$0A/$0B。サウンドドライバが間接アクセスで書くため、静的ASMの直値検索だけでは見落とした。 結果、妖精取得SEだけが終わらずループした。現在は $0778/$0779 へ移設済み。
新規RAMが必要な時の優先順位: まずRAMを増やさずROMテーブル再読込や既存カウンタ派生で済ませる。まとまったRAMが必要なら旧特殊ブロックリスト跡の $0750-$0767 は透明ブロック内アイテム用、$0768-$076F はひび割れブロック内アイテム用、$0770 はワープミラーモード状態用に予約済み。まとまったRAMは $0740-$074F と $0771-$0777 を候補にする。 長期保存・毎NMI書込・複数バイト連続使用は、先に専用probeで実機確認してから予約する。予約後は room_flags.py のASCII mirrorも同期する。
