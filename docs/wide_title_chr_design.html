Wide Title CHR Design

ワイドタイトルのCHR使用範囲、保護範囲、PNG取り込み方針を整理する作業台帳。2026-06-21 時点では「修正前の現在地」として、現在実装がどのPRG/RAM/CHR領域を使い、どこを使ってよいと見なしているかを棚卸している。

重要: この文書は作業中の設計台帳。下の「自由に使えるCHR範囲マスター」に入った範囲は確定扱い。まだ入っていない範囲は、現在実装が使っていても自由領域とは見なさない。

1. アドレスの読み方

呼び方意味例
stream値ワイドタイトルストリーム内の1バイトtile値。タイトル描画では _BG_BASE = 0x100 を足してCHR物理タイルへ変換する。stream 0x30 => CHR tile 0x130
CHR物理タイルCHR bank内の0から始まる8x8タイル番号。スプライトビューアの「bank内」と同じ見方で会話する。bank内 0x130
ROMファイル範囲NESファイル先頭からのオフセット。iNESヘッダ16バイトを含む。bank内 0x130 => file 0x17310-0x1731F

用途stream値CHR物理タイル / bank内ROMファイル範囲現在の扱い
CHR bank3 全体-0x000-0x1FF0x16010-0x1800Fタイトルで使うCHR bank。512 tiles。

低位タイトル/文字/BUILD系として保護寄り0x00-0x2F0x100-0x12F0x17010-0x1730F現在のPNG取り込みでは候補外。
PNG取り込みが使ってよい候補0x30-0xFF0x130-0x1FF0x17310-0x1800F仮の扱い。 上部以外で使っているstream値は除外する。
スプライトビューアでは、会話上は bank内 0x130 のように読む。これは上表の「CHR物理タイル / bank内」と一致する。

ワイドタイトルで自由に上書きしてよいと確定したCHR bank3内の範囲。PNG取り込み、BUILD文字、今後のタイトル部品などで同じ範囲を使うための人間用マスター台帳。実装側には、この台帳と同じ範囲を定数として持たせる。

4. 現在コードのPNG取り込み判断

対象: magatu_skc/core/title_screen.py の apply_title_top_image_from_png()。

処理現在の内容
上部範囲タイトル上部行を top_cells として取り出す。
保護対象上部以外で使っているstream値を used_outside として集める。
候補選定range(0x30, 0x100) のうち、used_outside に入っていないstream値を available にする。
実質的な意味bank内 0x130-0x1FF のうち、下部や別領域で使っていないタイルを上部PNG用に再利用する。
問題になりそうな点: 「今のワイドタイトル画面で上部以外に使っていない」ことと、「自由に上書きしてよいCHRタイルである」ことを同一視している。修正時は、上のマスター表を基準にした固定のCHR所有権表へ寄せる。

8. 修正方針メモ

論点現状修正時に決めること
自由CHR範囲bank内 0x12C-0x139, 0x13C-0x14F, 0x154-0x17F を確定済み。実装側のPNG取り込みやBUILD文字割当を、このマスター表基準へ移す。
保護CHR範囲bank内 0x100-0x12F は候補外。上部以外で使う 0x1A8, 0x1C0-0x1D0, 0x1D2-0x1DD も実行時に除外。BUILD文字、下部タイトル、固定部品、将来予約を所有者別に分ける。
PNG取り込み上部PNGの必要タイルを、候補poolから割り当ててCHRへ書く。固定poolだけへ書くのか、既存上部だけを再利用するのか、原作/US/ワイドタイトルごとに扱いを分けるのか決める。
会話上の基準スプライトビューアに bank内 表示を追加済み。今後は bank内 0x... で場所を指定して照合する。
