6. 次の整理方針

対象方針理由
毎フレーム敵AI原則PRG0維持ステージ実行中のbank切替は事故リスクと負荷が高い。
敵IDごとの属性/見た目/挙動表PRG1またはロード時RAMコピー候補大きい固定テーブルはPRG0に置く必要が薄い。
ステージ開始前だけ必要な処理PRG1活用候補ロード時ならbank切替の安全設計がしやすい。
強化敵 wrapper共通化候補現在は敵ごとに似た判定/分岐が増えており、PRG0断片を消費している。
