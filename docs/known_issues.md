# Known Issues

このファイルは、SOLOMON_CUSTOMIZERで確認済みの既知の不具合や制約を記録するためのものです。

このアプリでは、原作ROMへ多くの改造を追加しています。その中には、できるだけ解消したいものの、ROM容量の制約が厳しく、すぐに対処すると別の領域を大きく消費したり、他の機能へ影響したりするトレードオフがあります。

ここに記載する内容は、隠してよい問題ではなく、今後の修正候補として管理するものです。ただし、正式な修正方針が決まるまでは、無理に互換処理や救済処理を追加せず、現在作るROMを正しく動かすことを優先します。
