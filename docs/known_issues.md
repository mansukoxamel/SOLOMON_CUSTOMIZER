# Known Issues

このファイルは、SOLOMON_CUSTOMIZERで確認済みの既知の不具合や制約を記録するためのものです。

このアプリでは、原作ROMへ多くの改造を追加しています。その中には、できるだけ解消したいものの、ROM容量の制約が厳しく、すぐに対処すると別の領域を大きく消費したり、他の機能へ影響したりするトレードオフがあります。

ここに記載する内容は、隠してよい問題ではなく、今後の修正候補として管理するものです。ただし、正式な修正方針が決まるまでは、無理に互換処理や救済処理を追加せず、現在作るROMを正しく動かすことを優先します。

## Stage 49-50 start-screen K/P glyph corruption

### 状態

未修正。実質的に当面放置。

### 内容

49面と50面で、暗闇や魔法禁止などのステージ制限を設定すると、ゲーム開始前のステージ紹介画面に追加メッセージが表示されます。

このとき、追加メッセージ内でアルファベット `K` と `P` が使われると文字化けします。

具体例:

- 暗闇: `DARK ROOM` の `K` が文字化けする。
- 魔法禁止: `SPELL SEALED` の `P` が文字化けする。

ここでいうステージ紹介画面は、プレイ開始直前に `SHRINE` / `ROOM xx` などが表示される画面です。

### 原因

原作ROMでは、この開始前画面のCHR bankが面番号に応じて切り替わります。

- 1-16面: CHR bank 0
- 17-32面: CHR bank 1
- 33-48面: CHR bank 2
- 49面以降: CHR bank 3

現在の追加メッセージ用CHRは、bank 0-2にだけ追加しています。そのため、49面以降で開始前画面がCHR bank 3を使うと、追加文字 `K` / `P` のタイルが存在せず、必ず表示が崩れます。

### 修正時の注意

単純には、CHR bank 3にも `K` / `P` の追加タイルを書けば直せます。

ただし、CHR bank 3の該当位置はタイトル画面の文字にも使われています。そのため、ここを追加メッセージ用に上書きすると、今度はタイトル画面側の文字が使えなくなります。

つまり、現在のROM容量とCHR配置のままでは、49面/50面の開始前メッセージ表示とタイトル画面表示を完全には両立しにくい状態です。どちらかを優先する必要があり、現状ではタイトル画面を優先します。
