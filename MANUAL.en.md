# SOLOMON_CUSTOMIZER English Manual

This is the English manual for SOLOMON_CUSTOMIZER.

The English text is a practical translation of the Japanese manual. Some wording may be simple, but the goal is to make the tool usable.

## Important Notes

- SOLOMON_CUSTOMIZER edits and extends the Japanese NES version of Solomon's Key.
- The normal editing target is the mapper66 wide-title expanded ROM generated by this application.
- A raw Japanese ROM is treated as the source input. When it is loaded, the application converts it into the expanded editing format in memory.
- US ROMs are not normal editing targets. They are used only as limited material sources, such as title-screen import material.
- This project is still in active development. Old project files, old JSON schemas, old labels, and old temporary test ROMs are not guaranteed to remain compatible.
- Keep a backup of your original ROM and important work files.

## Requirements and Launch

### If a Packaged Version Is Available

If a packaged build is available, use the onedir zip package from the release page.

1. Extract the zip file.
2. Open the extracted folder.
3. Run `SOLOMON_CUSTOMIZER\SOLOMON_CUSTOMIZER.exe`.

Do not remove the `_internal` folder. The executable needs files in that folder.

If the application does not start, extract the zip again to a normal local folder such as the Desktop or `D:\tools\SOLOMON_CUSTOMIZER`.

### Running from Source

When running from Python source:

```powershell
python SOLOMON_CUSTOMIZER.py
```

Required modules are listed in `requirements.txt`.

## Basic Workflow

1. Open the original Japanese ROM.
2. The application converts it to the mapper66 wide-title editing format.
3. Edit stages, objects, palettes, title screen, and gameplay settings.
4. Use test play to check the current stage.
5. Save the ROM.
6. Keep the exported global settings and stage data together with the saved ROM.

## Window Layout

### Center Canvas

The center area is the stage canvas. Blocks, items, monsters, meta objects, and special markers are placed here.

### Left Pane

The left pane contains file operations, display options, edit tools, stage settings, and the selected object's properties.

Important controls include:

- Open ROM
- Reload
- Save ROM As
- IPS Patch Output
- Test Play
- Stage Data Load / Save
- Gameplay Hacks
- Enemy settings
- Palette Editor
- Sprite Viewer
- Title Screen Import

### Right Pane

The right pane contains the block, meta, item, and monster pickers. It also contains stage thumbnails, mirror details, favorites, and Panel Variant settings.

A second Test Play button is also shown on the right side for easier workflow when editing from the picker side.

## Mouse Operations

- Left click: place the selected object.
- Right click: delete the object at the cursor.
- Drag: paint continuously.
- Ctrl + drag: area selection.
- Drag and drop from picker: register to favorites or mirror slots where supported.

If "Edit 16th column" is off, the 16th column is protected from normal edit and delete operations.

## Keyboard Shortcuts

Common shortcuts:

- `Ctrl+Z`: Undo
- `Ctrl+Y`: Redo
- `F1`: Help
- `F9`: Settings

Other shortcuts depend on the active tool and dialog.

## Stage Editing

### Blocks

Select a block in the block picker and place it on the stage canvas.

The 16th column is special. It can be protected by turning off "Edit 16th column".

### Items

Select an item from the item picker and place it on the canvas.

Item state can be changed:

- Normal
- Hidden
- Inside block

### Monsters

Select a monster from the monster picker and place it on the stage.

Monster speed selection is available for supported enemies:

- SP1
- SP2
- SP3

Some enhanced monsters use custom IDs. These are project-specific extensions.

### Meta Objects

Meta objects are editor-side markers or special objects used by this customizer.

### Key-Holding Enemy

The stage can specify which enemy holds the key. Make sure the number is valid for the number of enemies in the stage.

## Stage Settings

### Tile Set

Choose the tile set used by the stage.

### Stage Time Limit

The stage time value controls the in-game time behavior. The UI also shows an estimated real-time duration.

The game updates at 60 frames per second. Frame-based values are converted to seconds where useful.

### Room Rules

Room-specific rules include:

- Disable B button fire
- Disable A button stone creation
- Hide the door
- Dark room mode
- Reset carried fire at stage start

### Zodiac

Choose the zodiac sign used by the stage.

### Panel Variant

Panel Variant A/B/C are enhanced Panel Monster variants.

For each group, the stage can define:

- Bullet speed preset
- Fire interval value

The default fire interval is `192` frames when no data exists.

The current speed presets include:

- `1/4`
- `1/2`
- `2x`

Panel Variant picker icons are shown with a blue marker to distinguish them from normal enhanced monsters.

## Demon Mirrors

Demon mirror settings are edited in the mirror detail dialog.

The mirror enemy lifetime value is shown there with a real-time seconds estimate. The old left-pane lifetime display has been folded into the mirror detail workflow.

The schedule controls when each mirror spawns enemies.

## Bonus Stage

Bonus stage item layout can be edited through the bonus-stage item area.

## Special-Process Markers

Special-process markers show custom behavior or internal ROM logic on the canvas.

Use the marker display option when you want to inspect special logic while editing.

## File Operations and Output

### Save ROM

Saving a ROM writes the customized ROM and related sidecar data.

The expected output set is:

- ROM file
- Global settings JSON
- Stage data files for all stages

If the title extra text is empty, the application may fill it with a build timestamp such as:

```text
BUILD 20260525 213546
```

### IPS Patch Output

Creates an IPS patch from the current customized ROM data.

### Stage Data Save

Stage data can be saved separately. This is part of the recovery and reproduction workflow.

### Stage Data Load

Stage data can be loaded back into the current project.

### Global Settings JSON Import / Export

Global settings include application-wide gameplay settings, palettes, demo input, enemy drop data, clear messages, and other global custom data.

Importing global settings can immediately apply some data to the in-memory ROM. This operation is not a simple undoable edit. If you need to restore the previous state, export your current settings first or reload the ROM.

## Test Play

The recommended emulator is Mesen.

Test Play creates a temporary ROM and starts the emulator for quick checking.

Test Play applies extra convenience patches such as title/start wait skipping. These patches are for test play only and are not part of normal "Save ROM" output unless explicitly implemented elsewhere.

## All-Stage Statistics

The statistics view summarizes stage contents across all stages.

Use it to inspect item counts, enemy counts, and other stage-wide information.

## Palette Editor

The palette editor changes global palette data.

If palette data is imported through global settings, the editor display and thumbnails should be refreshed to match the imported palette.

## Sprite / Character Viewer

The viewer supports several modes.

### ROM Frame Data Mode

Shows sprite frame data read from ROM structures.

### Character Mode

Shows character-oriented graphics for inspection.

### Raw CHR Tile Mode

Shows raw CHR tile data.

## Title-Screen Import / Editing

The title screen can be imported or edited.

The tool supports workflows for moving title graphics from US material to JP expanded ROM data.

### Top PNG Save / Load

The top title area can be saved to or loaded from PNG where supported.

### Extra Text

Extra title text is used to identify the build or version in-game.

If it is left empty, the application can generate a build timestamp.

### Title Color

Title colors can be adjusted through the title editing tools.

## Gameplay Hacks

Gameplay hacks change known ROM addresses or injected custom routines.

Do not assume every combination is safe without testing. Some features share tight ROM space and depend on a specific save order.

### Basic

Includes start stage, continue limit, initial lives, initial magic, and related global values.

### Player

Includes player movement and player-related behavior changes.

### Enemy / AI

Includes enemy movement, attack behavior, enhanced variants, Panel Monster variants, Spark Ball behavior, Gargoyle behavior, Salamander behavior, and other enemy logic.

Enhanced Saramandor uses movement speed 1 only. Enhanced Gargoyle A and B also both use movement speed 1, retain the LIFE-hundreds two/three-shot switch, and have independent bullet speed, shot interval, and cooldown settings.

Panel bullet speed correction affects enemies that use the same bullet speed table. This is intentional because the correction is based on the original game's shared bullet behavior.

Panel Variant A/B/C use borrowed monster IDs. Item drop behavior may follow the original borrowed ID group. This is an implementation detail and is treated as the current specification.

### Screen / Effects

Includes clear-screen behavior, dark room timing, and related display effects.

### Maintenance / Special

Some options are low-level ROM maintenance features. Use them carefully.

### Related Editors

The gameplay hack dialog also links to related editors such as:

- Enemy Drop Editor
- Demo Input Editor
- Clear Screen Message Editor
- Special-Process Viewer

## Enemy Drop Editor

The enemy drop editor changes global enemy drop tables.

These settings are global, not per-stage.

## Demo Input Editor

The demo input editor changes the attract/demo input sequence.

## Clear Screen Message Editor

The clear screen message editor changes the message shown on the clear screen.

## Settings

Settings include UI options such as font size and theme.

The current application supports a dark green/black style.

Configuration files are stored under the `config` folder when running from the project or packaged application.

## Undo / Redo and Dirty State

Undo and redo are available for stage editing operations.

Some global ROM operations may not be fully undoable. If an operation says it is immediately applied, treat it as a direct ROM-memory change.

## Supported Formats

Main supported input:

- Japanese Solomon's Key ROM

Main generated editing format:

- Japanese mapper66 wide-title expanded ROM

Normal editing does not target US ROMs.

## Limitations

- Backward compatibility with old temporary formats is not guaranteed during development.
- ROM space is tight. Some custom routines depend on exact placement.
- Some feature combinations require testing.
- The application assumes the expanded mapper66 editing format after loading.

## Troubleshooting

### ROM Cannot Be Loaded

Check that the ROM is the expected Japanese source ROM or a supported expanded ROM generated by this tool.

### Gameplay Hack Item Is Disabled

Some features are available only for supported ROM regions or expanded formats.

### Test Play Does Not Start

Check emulator path settings. Mesen is recommended.

### Stage Data PNG Cannot Be Loaded

Make sure the file is a stage data image created by this application.

### Saved ROM Behaves Strangely

Check whether multiple advanced hacks are enabled. Also check the ROM/RAM ledgers if the issue relates to injected routines.
